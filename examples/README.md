# Examples

Committed TM-BOM samples for demos, CI, and deep-links.

| File | Description |
| --- | --- |
| [`checkout-api.cdx.json`](./checkout-api.cdx.json) | Sample checkout API: blueprint scope/assumptions, controls, trust boundaries, attack paths/abuse cases, definitions, profiles, STRIDE + LINDDUN + ATT&CK, CAPEC, attack trees, scenarios, risks (with out-of-scope threat), BOM-Link refs |

Load in the UI via **Projects → Load examples/checkout-api.cdx.json**, or open:

```text
/?example=checkout-api
```

A copy is also published under `public/examples/` so the static app can fetch it (including on GitHub Pages).
